## 🚀 How to Preview Locally

Because this project is written in pure, standard modern web technologies (HTML5, CSS3, JavaScript), **no build step or compiler is required**!

### Option 1: Direct Browser Launch
Simply double-click `index.html` or right-click `index.html` → **Open with Google Chrome** (or Edge/Brave).

### Option 2: Using Node.js HTTP Server
In your terminal, navigate to this project folder:
```bash
cd "C:\Users\gowri\.gemini\antigravity\scratch\portfolio-gouri-shankar"
npx serve .
# or
npx http-server -p 3000
```
Then open `http://localhost:3000` in your web browser.

## 🌐 How to Deploy to GitHub Pages for FREE

Since you already have GitHub at **[github.com/shankarreddy1438](https://github.com/shankarreddy1438)**, you can host this live on the web in 3 minutes:

### Method A: User Site (`https://shankarreddy1438.github.io`)
1. Log in to [GitHub](https://github.com/) and click **New Repository**.
2. Name the repository exactly: `shankarreddy1438.github.io`
3. Set visibility to **Public**.
4. In your terminal inside the portfolio folder:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Gouri Shankar Reddy Portfolio"
   git branch -M main
   git remote add origin https://github.com/shankarreddy1438/shankarreddy1438.github.io.git
   git push -u origin main
   ```
5. Your portfolio will automatically be live worldwide at:
   👉 **`https://shankarreddy1438.github.io`**

### Method B: Repository Page (e.g. `portfolio`)
1. Create a repository named `portfolio`.
2. Push your files:
   ```bash
   git init
   git add .
   git commit -m "Deploy portfolio website"
   git branch -M main
   git remote add origin https://github.com/shankarreddy1438/portfolio.git
   git push -u origin main
   ```
3. Go to **Settings** > **Pages** in GitHub.
4. Under **Branch**, select `main` and root `/`, then click **Save**.
5. Your site is live at: `https://shankarreddy1438.github.io/portfolio`!
